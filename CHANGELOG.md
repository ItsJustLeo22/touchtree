# Changelog

## 1.0.0

First release.

- Files pane for the Claude Code desktop app, opened with `/touchtree`.
- Status card: what Claude is doing right now, or what it did last turn, with branch, commits ahead, and lines changed.
- Claude touched list: every file Claude read or edited this session.
- Lazy project tree that opens folders to show the file Claude is working on.
- Rounded highlights for files Claude read (purple), edited (orange) and committed (green), with a matching pill.
- Folders take the colour of the strongest action inside them (committed, then edited, then read) and shimmer while Claude works in them.
- Files Claude creates or changes through shell commands count as edits.
- File search, collapse all, sizes, hidden-file toggle, and folder navigation.
